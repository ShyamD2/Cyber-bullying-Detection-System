About CyberGuard AI

An automated Machine Learning and Natural Language Processing (NLP) system designed to detect, classify, and mitigate cyberbullying and online toxicity.

Purpose & Objective

With the rapid growth of social media platforms, cyberbullying has emerged as a critical societal issue affecting millions of individuals globally. Traditional manual moderation cannot scale to handle millions of posts generated every second.

This project provides a robust, machine-learning-driven solution capable of identifying toxic messages in real-time. By classifying content into specific harassment categories (such as gender-based toxicity, racial/ethnic discrimination, religious hate, and general abusive language), the system enables proactive online protection.

How NLP Detection Works

  1. Text Preprocessing: Converts raw text to lowercase, removes URLs, user mentions (@username), hashtags (#), numbers, punctuation, and stopwords using NLTK.
  2. Lemmatization: Reduces words to their canonical dictionary root forms using WordNet Lemmatizer.
  3. TF-IDF Vectorization: Transforms text into numerical feature vectors based on Term Frequency-Inverse Document Frequency.
  4. ML Classification: Classifies vectors using trained Machine Learning models (Linear SVM, Logistic Regression, Naive Bayes, Random Forest).
